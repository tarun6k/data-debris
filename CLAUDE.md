# Data Debris — project rules for Claude Code

## What this is
Native macOS disk cleaner. Tagline: "find it, review it, clear it".
Specs: docs/product-spec.md (authoritative, sections §1–§15), docs/ui-spec.md (Screens 0–13),
design PNGs in docs/design/. When a spec and this file disagree, the spec wins; tell me.

## Stack (fixed)
Swift 5.10, SwiftUI + AppKit where needed, Swift Concurrency, CryptoKit (SHA-256),
SQLite via GRDB, Sparkle 2 for updates (Phase 8). Payments: Paddle Billing as merchant of
record (Paddle Sandbox in Debug), plus a small license service (Cloudflare Worker) that
turns Paddle webhooks into Ed25519-signed license keys and answers activate/validate/
deactivate with a 2-Mac limit (Phase 7). Deployment target macOS 13. Universal binary.
NOT sandboxed (direct distribution). Hardened Runtime on.
Xcode project generated by XcodeGen from project.yml.
Layout: Sources/DebrisCore (engine, no UI), Sources/DebrisApp (SwiftUI), Tests/,
services/license-worker (TypeScript, Phase 7).
Signing during development: no team, "Sign to Run Locally". Never block on a team ID.

## Safety invariants — never violate; each one gets a test
S1 Allowlist only: a file is removable only if a catalogue rule claims it. Unknown = untouched.
S2 One gate: every manual removal passes through ReviewView. Auto Clean removes only rules
   ticked on AutoCleanView AND marked autoCleanEligible.
S3 Trash by default via FileManager.trashItem. Permanent delete is per-run, double-confirmed,
   never in Auto Clean.
S4 Journal before move: item row written and fsync'd BEFORE the move.
S5 Undo while items remain in Trash; restore to original path or " (restored)" suffix.
S6 Re-verify at clean time: re-stat; skip if size/mtime/inode changed or file is open.
S7 A duplicate group never ends with zero kept copies.
S8 User authority only: no root, no privileged helper, no sudo, ever.
S9 No silent scope creep: external volumes opt-in by UUID; new rules ship unticked for Auto Clean.
S10 Honest numbers: allocated blocks; clones/hardlinks excluded; "moved to Trash" is not "freed".

## Protected paths (hard-coded, shown in Settings, never preferences)
/System /usr /bin /sbin /private/var (except user tmp) /Library, other users' homes,
*.app bundles, Photos/Music/TV/Books/Final Cut/Logic libraries, Lightroom catalogs, Mail data,
VCS working trees (.git/.hg/.svn) except .gitignore'd build dirs,
~/Library/{Application Support,Preferences,Containers data,Keychains,Mobile Documents},
Time Machine and APFS snapshots, open/mmapped files, dot-files in the home root.

## Monetisation rules
Free: unlimited scans and full results. Paid: 1 Year $20, 3 Years $50, 2 Macs each.
Before any price is shown, the Privacy & Security sheet must be acknowledged (scrolled to
end + unticked checkbox ticked). Auto-renew is OFF by default. Lapsed = back to Free;
History and Undo keep working. Secrets (Paddle API key, webhook secret, signing key) live
in .env / wrangler secrets / Keychain — never in the repo or a prompt.

## Copy rules
Buttons name the amount ("Clean 9.7 GB", "Restore 1,318 items"). No exclamation marks.
Never "boost", "optimize", "junk is slowing down your Mac". No emoji in the UI.
Sizes like Finder (GB/MB) with tabular figures. Paths in monospace, middle-truncated.

## Working style
- Engine code gets tests before UI. Run `make test` before saying a step is done.
- Small commits with conventional messages.
- Ask before adding any dependency beyond GRDB, Sparkle and XcodeGen.
- If unsure whether a path is safe to delete, it is not: report it as "unknown" instead.
